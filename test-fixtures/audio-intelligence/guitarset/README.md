# Four real acoustic guitar validation clips

These four `audio_mono_mic` WAV files and `ground-truth.json` are from [GuitarSet v1.1.0](https://zenodo.org/records/3371780) by Qingyang Xi, Rachel M. Bittner, Xuzhou Ye, Johan Pauwels, and Juan P. Bello, mirrored in [`jhartquist/guitarset`](https://huggingface.co/datasets/jhartquist/guitarset) at commit `4aca25487bef5cb0d2c4ec146218f9145402a776`. The source is licensed CC BY 4.0; see `LICENSE` for attribution and terms. The WAV files are the original mono microphone captures served by that mirror. `ground-truth.json` retains the mirror's chord and beat annotations for rows 0, 20, 24, and 26, plus SHA-256 hashes of the exact WAV files. No audio or annotation was generated by FretShift.

The selected rows are all acoustic composition excerpts by player 0: bossa nova, funk, and two jazz tempos. This is a small validation sample, not a representative test of electric guitar, singing, drums, or full bands. The annotations include complex chord symbols outside FretShift's classifier vocabulary. `scripts/bench-audio-real.mjs` scores roots across labeled time and exact labels only where an unaltered reference label is directly representable. It never converts a complex reference chord to a simpler label.

Run `pnpm bench:audio-real` from the project root. The script verifies WAV hashes and writes `AUDIO_INTELLIGENCE_REAL_BENCHMARK_RESULTS.json`.
