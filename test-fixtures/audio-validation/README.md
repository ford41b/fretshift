# Additional acoustic evaluation cohort — post Phase 3

Four unchanged mono-mic GuitarSet v1.1.0 recordings: players 1 and 2, BN1 at 129 BPM, one comping and one solo performance each. CC BY 4.0; attribution/terms in LICENSE. Original: https://zenodo.org/records/3371780 ; mirror: https://huggingface.co/datasets/jhartquist/guitarset at revision 4aca25487bef5cb0d2c4ec146218f9145402a776. Retrieved 2026-09-26 local date (UTC 2026-09-27), rows 60, 61, 120, 121. Each JSON retains unmodified source notes, chords, beats, metadata, row URL and WAV SHA-256. Signed expiring audio URLs are not required for reproduction: all files are included.

Original unmodified JAMS for these four files are also retained from Zenodo annotation.zip (upstream MD5 b39b78e63d3446f2e54ddb7a54df9b10). Extracted downbeats come only from beat_position entries where value.position=1. All extracted beat timestamps were checked against mirror beats_s. Ground-truth.json contains comping reference labels/timing and audio/JAMS hashes for the chord benchmark. Source beat/chord boundaries follow the supplied score-aligned annotation; they have not been independently listening-audited as expressive performance timing. These excerpts have constant annotated tempo. Do not claim variable-tempo or modulation coverage.

This cohort was selected by player and row before evaluating; no detector threshold was changed on it. It adds players, not electric, distorted or ensemble conditions. Solo still has ringing overlaps; comping note scores are unsupported-polyphony probes. Open/barre shapes, picking technique and actual string agreement are not certified here.

Run node scripts/bench-audio-real.mjs test-fixtures/audio-validation docs/post-phase-3-validation/expanded-chords.json and node scripts/bench-audio-notes.mjs test-fixtures/audio-validation docs/post-phase-3-validation/expanded-notes.json. The latter also repeats the five synthetic controls. Do not count repeated synthetic controls as new recordings.
