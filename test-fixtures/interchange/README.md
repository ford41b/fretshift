# Independent interchange fixtures

These fixtures exercise files that were not produced by Fretshift or by its tests.

- `alphatab-chords.gp5` comes from alphaTab's `packages/alphatab/test-data/guitarpro5/chords.gp5` fixture.
- `musicxml-testsuite-71e-tab-staves.musicxml` comes from alphaTab's copy of the MusicXML test suite, `packages/alphatab/test-data/musicxml-testsuite/71e-TabStaves.xml`.

Both were retrieved from the alphaTab `develop` branch on 2026-09-12. The alphaTab repository is licensed under MPL-2.0. Keep these files unchanged so they remain independent compatibility evidence.
