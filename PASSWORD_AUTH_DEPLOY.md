# FretShift password auth

FretShift supports:
1. 8-digit verification code
2. Magic link
3. Email + password

New private-beta users can create a password account without waiting for an email.

Existing users who originally signed in with a verification code or magic link do not automatically have a password. They should sign in with their existing method once, open Account & sync, expand **Set or change password**, and save a password. After that, the same account can use Email + password sign-in.
